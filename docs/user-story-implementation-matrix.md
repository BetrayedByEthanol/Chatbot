## How to read this register

- **I — Implemented core:** central behavior has a matching implementation and associated test coverage; not a claim that every acceptance criterion or legacy candidate has passed.
- **P — Partial:** meaningful implementation exists, but a required behavior, scope, integration or material acceptance evidence remains open.
- **M — Missing / not located:** no implementation of the named capability identified in the inspected milestone documentation and repository inventory; adjacent modules are pointers, not proof of that capability. Reassess if additional evidence is found.
- Authority and phase priority are copied from the master backlog. I/P/M is independent of authority; proposed-only stories are not release blockers unless explicitly adopted. The confirmed behavioral core of mixed stories remains binding.
- Code and test columns are traceability pointers. Milestone docs and selected code/test entry points were inspected; all linked paths were checked against the pinned Git tree. Not every file, function, or acceptance criterion was exhaustively inspected. No new tests were executed for this document. Treat classifications as provisional until individual criterion review.
- Test file presence does not mean execution or success. PR #102 head `bc34a75222f7c408e4ff6eab3c68711269c216e4` had successful Phase 0 contracts and Phase 1 live integrated acceptance workflows; this is evidence for the tested PR head, not an independent execution on the merge SHA. See [PR #102](https://github.com/BetrayedByEthanol/Chatbot/pull/102) and the [workflow definitions](../.github/workflows/).
- The 25-turn regression uses a stub model with real PostgreSQL and workers. Local real-model comparison and genuine independent reviewer acceptance must be evaluated separately. Private operator artifacts, reviewer identities, full prompts and transcripts are intentionally not committed.
- Historical November 21 audit at `55fa3dd`: 52 implemented / 52 partial / 20 missing. Its row-level assessments were not supplied; this new register uses its own provisional classifications, not a mechanical post-PR delta. Do not interpret the difference as a count of newly completed stories.
