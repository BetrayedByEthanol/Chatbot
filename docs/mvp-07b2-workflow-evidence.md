# MVP-07B2 — Procedure and Task evidence dependencies

Fifth bounded increment after PR #136. Use existing scoped immutable source, approval, report, step, evaluation and adaptation records. Do not add a generic provenance graph, mutate fixed definitions, revoke approved Goals, undo actual work, or convert an interpretation into execution authority.

## Contract

- Migration 0061 reuses the exact Memory source policy from 0060 at the owner boundaries. A Task confirmation depends on both its own source/approval and the exact DONE report/approval. Existing transitive Task DAG confirmation pins remain authoritative. Invalidated reports/confirmations are not effective completion or recurring progress; no fallback to older evidence. Task plan evidence blocks new actionable work, not truthful historic completion. Explicit correction/cancellation remains possible.
- A private method revision depends on its own source/approval. An applied adaptation also depends on the exact proposal, evaluation, source step evidence and predecessor revision, bounded to 32 adaptation links. A new complete, explicitly approved manual revision is independent of the old chain. Shared approved templates are unchanged.
- ProcedureRun checks its immutable run/variant/task pins and effective step events. Confirmation also checks the preceding DONE event; a same-status instruction receipt cannot substitute for underlying progress. Owner corrections remain effective review barriers. Stored statuses and actual read-only operation results remain historical facts; run/step views expose separate eligibility. Stale runs do not supply step instructions through guided or optional Procedure context; a new approval or explicit owner correction is required. Pause/cancel remain available. No automatic replay, rerun or completion.
- Task/Procedure owner writes revalidate the evidence under the existing historical scope SHARE lock after owner/event writes. Model context and bound canonical guidance use the existing historical response fence; ordinary unbound guidance refusals do not need it. Memory corrections during inference or before controlled delivery invalidate the reply. Existing run version and dialogue fences remain. ACK orders its linked run lock before the historical lock.
- AGENT authorization additionally pins the direct Task prerequisite confirmation IDs (transitive dependencies already pinned by Task). Legacy unknown pins with current prerequisites fail closed. The existing gate checks plan, run, effective prerequisites, exact approval/renewal source chain and the pinned IDs at stage, enqueue, claim, dispatch, completion and reconciliation. Final execution/completion/reconciliation checks serialize with Memory changes; orphan attempt results are not accepted as progress. Claim scans use read-only checks. No external action is undone. A late race in reconciliation rolls back the acceptance; subsequent reconciliation invalidates the grant. Existing lease cancellation/recovery remains authoritative.
- Evaluations and private adaptation proposals have source eligibility; stale outcomes are not counted as current experience or strategy observations. Historical views expose the original evidence with an eligibility flag. A superseded evaluation does not justify a new adaptation. No automatic revision application.

## Boundaries

The exact owner-linked Memory policy is not general semantic correction detection. Approved Goals and shared procedure definitions are deliberately not revoked. Task priority/edge decisions, full goal evidence, procedure finish/status action history, unowned dialogue copies, all canonical output dependencies, and derived indexes are not exhaustively tracked. A run's live task prerequisite check is distinct from the AGENT grant's exact snapshot; model optional Procedure context is protected against Memory changes and existing run versions, not every Task DAG transition after preparation. Previously emitted bytes or actual tool results cannot be erased by invalidating their use. Conservative whole-turn checks may require reassessment of valid work; private adaptation and renewal chains over 32 links fail closed. Query cost needs measurement. No remote deployment authorization.
