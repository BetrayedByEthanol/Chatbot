# MVP-07B2 — Summary source eligibility and range lineage

Second reviewable increment, based on main `2ca8985`. PR #132 protected response replay/delivery and omitted known response-derived evidence. A compressed range and its episodes could still preserve a superseded raw Memory source, including text from a different turn than an episode's citation.

## Contract

- Reuse Memory's existing explicit-report eligibility and exact memory revision/record checks. Do not infer semantic equivalence, classify all raw text or confer verification. Ordinary unowned reports remain evidence of user speech.
- A summary snapshot retains range positions. A known ineligible source has empty user text, an explicit source_omitted flag in model JSON, no assistant body and no delivered follow-up at that anchor. Follow-ups with ineligible origin turns are also omitted. The original conversation and delivery history are unchanged. The model cannot cite omitted user text; the existing exact-span and model-visible quote checks remain in force.
- Migration 0058 adds an optional source_turn_ids array on the summary: at most 16 eligible raw anchors plus two model-visible follow-up origins per anchor, distinct and scoped to the conversation. The source set is host-derived, not model supplied. Empty arrays are valid when no source text was eligible. NULL means legacy unknown projection; read conservatively checks the original range and known follow-up origins delivered by summary creation. No guessed backfill.
- Recheck the projected digest before writes and again at the existing historical-revision row lock after domain/event writes. An exclusive lock avoids a shared-lock upgrade with deferred summary/episode revision triggers. No subsequent Memory owner row locks; inference remains outside transactions. A changed input or expired lease rolls back the complete transaction. The existing worker retry/recovery policy remains authoritative.
- At summary context and existing episode eligibility reads, require every included scoped source to remain eligible. The episode's existing exact-source eligibility and quote checks remain in place. A whole range may be suppressed even when an individual episode cited another eligible turn; the model saw the entire range. A fresh summary of a range with masked inputs may remain eligible if its actual sources are current. No watermark rewind or automatic resummarization.

## Boundaries

This increment is deliberately narrow: exact Memory revisions and explicit report eligibility, including existing dispute/expiry checks. No generic raw-turn revocation policy, ordinary foreground context fencing, complete response-derived or transitive reflection lineage, automatic entity/relationship source invalidation beyond existing Memory checks, procedure/task/index propagation or physical erasure. Legacy ranges do not prove complete lineage; prior assistant-derived copies may still lack source attribution. Existing pattern/episode readers inherit the parent-range gate through the shared episode eligibility helper, not a new domain owner. Eligibility is checked on read; no stored summary or episode text is rewritten. Source re-eligibility follows owner rules, not deletion semantics.
