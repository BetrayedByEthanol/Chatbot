# MVP-07B2 — Derived retrieval and projection eligibility

Sixth bounded increment after PR #137. The existing PostgreSQL FTS indexes over owner rows, raw turns, episodes, patterns and document passages are candidate-selection mechanisms, never evidence authority. No persistent vector-memory index, embedding payload store or cross-request retrieval result cache was found in the current runtime/migrations inventory. No speculative indexing service is introduced.

## Contract

- Existing Memory record, summary/episode, entity and personal-meaning owner gates remain in place. Raw historical fallback already excludes Memory revision/candidate turns and unmanaged entity sources; do not expand retrieval eligibility. Index contents are not erased on invalidation: current scoped owner predicates control visibility before scoring and rendering.
- A pattern depends on the entire committed cognitive job input set (exact raw turns and every supplied historical episode snapshot), not only the support/counter IDs chosen by the model. Reuse the existing job metadata from 0059; unknown legacy lineage fails closed. Preserve current-version selection and original counterevidence, never fall back to an older pattern version. Existing deduplication remains unchanged: an identical cited-evidence fingerprint does not create a replacement merely because the model ran again.
- Routine responses that actually include compacted summaries capture the historical revision/next-expiry before reading the projection. Preserve the same fence through prompt budget convergence; response commit and existing replay/offer/ACK/speech checks enforce it. This is intentionally conservative across unrelated scope updates, consistent with prior historical response lineage. No new cache or external call under a lock. Personal-fact canonical rendering takes its Memory slot SHARE lock before validating the original summary fence; never acquire the historical scope lock first.
- MetaMemory history preserves the original observed outcome, references and feedback. Expose a separate current-source flag. The latest AVAILABLE observation with invalidated response or request evidence becomes a STALE open gap immediately, with no stale refs in the effective view; do not fall back to an older success. Expired feedback source is not effective review feedback. Repeated-ambiguity suppression requires the prior observation's response lineage to remain current. Historical feedback admission remains possible for actual delivered responses, not a new factual assertion.
- Document retrieval revalidates exact source and approval turns in addition to existing active current document/version, privacy, expiry, passage offsets and checksum. Procedure-conditioned search also checks eligibility of the current referenced private revision; an independently approved document remains generally searchable if only its procedure association is stale. Admission checks source and referenced revision evidence again under the existing exclusive scope lock after owner writes, with no new owner locks afterward. Withdrawal remains possible.
- Passage feedback ranking is tied to exact document version, passage, hash and query; an invalidated latest feedback source is neutral rather than reviving older feedback. History is unchanged.

## Boundaries and verification

This is not physical removal from FTS indexes, WAL or immutable history, nor a new cache coherence protocol for future vector search. Any future vector index must return scoped candidate IDs and source revisions and hydrate only via current owner gates; cached text is never sufficient. Complete structured dialogue/intent, affect, task priority/edge decisions, canonical tool/event projections and other owner-specific lifecycle coverage remain open. The broad summary/MetaMemory fences may invalidate otherwise independent content after unrelated changes; exact snapshot lineage is a future optimization. Query performance and migration/upgrade behavior require review. No automatic regeneration, erasure or remote deployment approval.

Regression tests exercise uncited pattern inputs, summary-conditioned routine response fencing, stale cached recall gaps, invalid document provenance and procedure association, and stale ranking feedback.
